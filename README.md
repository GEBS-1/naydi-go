# НайдиGo

Адаптивный демонстрационный прототип локального поиска товаров и кабинета магазина.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Проверка production-сборки: `npm run build`.

## Демонстрационный сценарий

1. Откройте «Для бизнеса» и зарегистрируйте магазин.
2. В кабинете добавьте товар, цену, количество и фотографию.
3. Перейдите на публичную часть и найдите товар по названию, категории или ключевым словам.
4. Отправьте запрос о наличии.
5. Вернитесь в кабинет → «Обращения» и ответьте покупателю.

Данные сохраняются в локальном хранилище браузера и переживают обновление страницы. Кнопка «Сбросить демо» возвращает 3 тестовых магазина, 24 товара и тестовые обращения.

## Карта

Прототип использует виджет Яндекс Карт без ключа и формирует внешние ссылки маршрута по координатам магазина. Переменная `NEXT_PUBLIC_YANDEX_MAPS_API_KEY` зарезервирована для подключения полноценного JS API с перетаскиваемым маркером.

## Развёртывание

Проект экспортируется как статический Next.js-сайт в `out/` и подходит для Cloudflare Pages, Netlify, Vercel и любого статического хостинга.

## Ограничения демо

- Данные и загруженные изображения хранятся в браузере текущего устройства, а не в общей серверной БД.
- Нет авторизации, SMS-проверки, оплаты и доставки.
- Ответ магазина виден в кабинете; отдельная история гостя на другом устройстве не реализована.
- Для полноценного поиска адреса и перетаскивания маркера нужен ключ Яндекс Карт.
- Все стартовые магазины, товары, цены, остатки и обращения помечены как «Демо» и являются вымышленными.
