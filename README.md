# НайдиGo

Городской поиск товаров, услуг и организаций Казани с сохранённым кабинетом владельца магазина.

Статус нового поискового движка, фактические тесты, ограничения RouterAI и расходы: [SEARCH-MVP-REPORT.md](SEARCH-MVP-REPORT.md). Полный MVP ещё не принят: поиск организаций и маршруты работают, внешние товарные предложения и распознавание фото требуют восстановления доступа RouterAI и дополнительных проверок.

Текущая реализация: Next.js-совместимый Vinext, React, TypeScript, Tailwind CSS, постоянная база D1 и фотографии в R2. Магазины, публикации, остатки, обращения и ответы общие для покупателя и владельца; данные не хранятся только в браузере.

Полная инструкция запуска, развёртывания, проверок и ограничения: [README-DEPLOY.md](README-DEPLOY.md).

Основная команда разработки: `npm run dev`. Перед первым запуском выполните установку, сборку и локальную миграцию из инструкции.

`/` — рабочее приложение. `/design/home` и остальные `/design/*` — сохранённые отдельные визуальные макеты, не рабочий каталог.

`/onboarding` — предварительное подключение магазинов администратором. Пять приватных витрин Казани и 25 товаров сохранены в локальной базе. Источники: [SOURCES-KAZAN.md](SOURCES-KAZAN.md). Персональные ссылки находятся в игнорируемом файле `artifacts/LOCAL-PREVIEWS.md`.

Перед внешним запуском необходим доверенный auth-шлюз; по умолчанию собранный сервер не доверяет входящим заголовкам личности. Подробности и ограничения — в инструкции.
