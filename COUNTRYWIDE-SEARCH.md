# Поиск по городам России

Изменения локальные; данные сохранены, production не менялся.

- Город выбирается кнопкой внутри поисковой строки. Ручное значение хранится в localStorage `ng_city`, имеет приоритет перед IP и геолокацией. Нет обязательной регистрации.
- IP-определение использует доверенное `Request.cf.city/country` Cloudflare, без передачи IP стороннему сервису. Английское имя при возможности нормализуется геокодером. Заголовки клиента `cf-ipcity`/`x-forwarded-for` не считаются доверенной геолокацией.
- На localhost или хостинге без Cloudflare metadata нет вымышленного города по умолчанию: предлагается ручной выбор или геолокация. На обычном VPS автоматическое IP-определение требует отдельного доверенного GeoIP-адаптера; оно не объявляется настроенным одним запуском Node.
- По действию пользователя браузер запрашивает координаты. `/api/location` определяет город через Photon. Координаты передаются POST-телом, не сохраняются в D1, URL или localStorage. Если геолокация относится к другому городу, ручной выбор не перезаписывается и координаты не используются для ложного ранжирования.
- При смене города отменяются старые клиентские запросы, очищаются выдача, выбранная точка, контекст уточнения, близость и маршрут. Компонент маршрута пересоздаётся для нового города. Адресные подсказки получают выбранный город.
- Внутренняя база фильтруется по городу; внешний поиск получает city; кеши веб-поиска, каталогов, OSM и геокодирования разделены по соответствующим параметрам. OSM геокодирование ограничено Россией; маршрут дополнительно учитывает коридор движения, поэтому может пересекать границы города.
- Новые ИИ-подборки используют выбранный город, а не жёстко заданную Казань. Существующие сохранённые подборки сохраняют свой город.

## Ограничения охвата

Общероссийская география не означает наличие всех товаров во всех городах. Проверенные региональные каталоговые адаптеры пока казанские и **не** подставляются в другие города. В остальных городах доступны публичная собственная база, организации OSM и общий веб-поиск, когда доступен RouterAI. Полнота источников различается; неизвестные цены/остатки не придумываются.

Незавершённый резерв RouterAI по просьбе владельца не изменён: платный веб-поиск/фото остаются заблокированы до сверки. Photon/Overpass имеют квоты, краткие блокировки параллельных вызовов и fallback; общероссийский запуск требует договорных/собственных геосервисов при росте нагрузки. Ограничение маршрута 250 км сохранено как технический лимит, не привязка к Казани.
