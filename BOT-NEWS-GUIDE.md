# НайдиGo: сообщения пользователям

Регистрация и рассылка независимы. Вход не подписывает на канал и не разрешает рекламные сообщения. Новая подписка — только команда `/subscribe` в личном чате бота, отказ — `/stop`. Бот объясняет содержание и частоту до согласия. В базе сохраняются идентификатор, время, версия согласия и текущее состояние. Существующие пользователи не подписаны автоматически.

## Отправка

1. Подготовьте UTF-8 файл на сервере, например `/var/www/naydi-data/news.txt`. Короткий полезный совет, ссылка на сайт. Не включайте персональные данные. Рекламные материалы требуют отдельной проверки применимых правил маркировки перед отправкой.
2. На сервере из текущей директории релиза НайдиGo выполните предварительный просмотр:

   `python3 scripts/send-bot-news.py --text-file /var/www/naydi-data/news.txt`

3. Проверьте текст и число добровольных подписчиков. Для фактической отправки добавьте `--send`.
4. Скрипт автоматически добавляет `/stop`, проверяет подписку перед отправкой, ограничивает частоту одним сообщением за 24 часа на получателя и исключает повтор идентичного текста. Неопределённые отправки не повторяются автоматически. Статистика хранится в `bot_news_deliveries`. Не удаляйте записи для повторной отправки.

Никакой ежедневной автоматической рассылки пока нет. Начните с редких полезных сообщений; не отправляйте однотипные напоминания ежедневно. Текущая функция — личные сообщения ботов, не публикации в каналы. Для каналов сначала нужны их публичные ссылки и права администратора.

## Яндекс ID

В этой версии вход через Яндекс ещё НЕ реализован и не включён. Настройка Яндекс Карт не даёт OAuth-доступа. Владелец должен создать приложение Яндекс ID для веб-сайта и передать Client ID, а Client secret сохранить только в серверном окружении. Затем необходимо реализовать и проверить серверный OAuth callback со state, обменом кода и получением подтверждённого идентификатора. URI callback согласовать до регистрации приложения. Не включать кнопку входа до сквозной проверки. Не объединять аккаунты Telegram/MAX/Яндекса автоматически по имени или email.
