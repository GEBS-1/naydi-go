# Вход через Яндекс ID

Код готов, но без приложения Яндекс OAuth реальный вход не включается. Создайте приложение для авторизации веб-сервиса «НайдиGo»: https://oauth.yandex.ru/client/new/id/

- Сайт: https://naydigo.prepromo.ru
- Redirect URI (точно): https://naydigo.prepromo.ru/api/buyer/yandex/callback
- Права: `login:info`. Почта, телефон, дата рождения не нужны.
- Серверные переменные: `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `YANDEX_AUTH_ENABLED=1`.
- Существующий `AUTH_BASE_URL` должен быть `https://naydigo.prepromo.ru`.

Секрет не присылать в чат, не добавлять в Git. Вписать в локальный игнорируемый `.env` для штатной выкладки или `/var/www/naydi-data/runtime.env` (JSON-quoted значения, права 0600). Перезапустить только naydigo. Пока настройки отсутствуют, кнопка скрыта.

Приёмка после настройки: открыть /account → Яндекс → разрешить вход → проверить имя и Free-баланс → обновить страницу → выйти → войти снова. Проверить отказ пользователя и просроченную ссылку. Аккаунты разных провайдеров не объединяются автоматически, вход не подписывает на рассылку.

Реализованы серверный code exchange, PKCE S256, одноразовый state, привязка к HttpOnly cookie браузера, 5-минутный срок, фиксированный callback, проверка client_id профиля. OAuth-токены не хранятся. Сессия НайдиGo действует 30 дней. Тесты с фикстурами не заменяют вход через реальное приложение Яндекса.

Документация: https://yandex.ru/dev/id/doc/ru/codes/code-url и https://yandex.ru/dev/id/doc/ru/user-information
