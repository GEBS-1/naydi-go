## Проверки релиза

- `npm run test:search`, `node scripts/test-search-quality.mjs`, `npm run test:seller:postgres`, `npm run test:listings -- http://127.0.0.1:3001`, `npm run test:result-cards`, `npm run test:chat:postgres`, `npm run test:chat:browser`, `npm run typecheck`, `npm run build` прошли. `npm run lint`: 0 ошибок, 68 предупреждений. Typecheck/build повторены после последних правок.
- Production smoke прошёл: HTTPS-страницы и клиентские файлы, Telegram/MAX начало входа, отказ поддельным webhook, запрет анонимного создания магазина и объявления. Браузер на самом VPS проверил 11 карточек, карту, товарную ссылку и страницу продавца на 390 и 1440 пикселях.
- Внешняя доступность **не подтверждена**: 11 ноября с рабочего компьютера TCP 80/443 и HTTPS до `5.252.116.49` завершались тайм-аутом, хотя порт 22 иногда доступен. На VPS nginx слушает 80/443, UFW разрешает их, внутренний HTTPS возвращает 200. Причина может быть на сетевом пути или вне VPS; перед рекламой нужно проверить сайт с независимой мобильной сети и устранить проблему, если она повторится.
- Живое подтверждение входа владельцем через бот и проверка публикации на его настоящем аккаунте пока не выполнены. Тестовые продавцы и товары не публикуются в production.

## Безопасность релиза

- Код выкладывать через `scripts/deploy-vps.py`: backup PostgreSQL и фотографий, проверка изолированного восстановления, сборка нового релиза, health и HTTPS, затем удаление только неактивного кода НайдиGo.
- `/var/www/naydi-data` и чужие проекты не очищать. Не включать demo/trusted headers в production.
