# НайдиGo — По дороге

Локальный запуск: `npm run dev`, затем http://localhost:3000/. Под основной строкой поиска выберите «По дороге», введите товар, выберите два адреса из подсказок, транспорт и нажмите «Найти товары по дороге». Геолокация запрашивается только отдельной кнопкой; можно обойтись ручным вводом.

## Данные и безопасность

Используются существующие D1 shops/products и тот же rankSearch. Черновики, демо, testOnly и неопубликованные товары исключаются на сервере. Для участия магазину требуется `addressConfirmed: true`, адрес и корректные координаты. Флажок добавлен в форму администратора и профиль владельца; при изменении адреса/координат в форме подтверждение сбрасывается. Старым магазинам подтверждение автоматически не присваивается. Пять персональных витрин остаются закрытыми.

В таблицу searches записываются только запрос товара, число результатов и время. Координаты пользователя и маршрут туда не записываются. Кнопка «Заехать» передаёт в Яндекс Карты три точки в порядке начало → магазин → исходное назначение и выбранный транспорт. Яндекс может рассчитать иной путь/время.

## Провайдеры и ограничения локальной версии

- Photon — подсказки адресов, `PHOTON_URL` (по умолчанию https://photon.komoot.io).
- Valhalla — дорожные/пешеходные маршруты, `VALHALLA_URL` (по умолчанию https://valhalla1.openstreetmap.de).
- Карта — реальные тайлы OpenStreetMap, геометрия от Valhalla; увеличение/уменьшение и возврат к полному пути, без перетаскивания.
- Область первого запуска: Казань и окрестности (55.3–56.3 N, 48.4–50 E). Подсказки нужно выбирать, не только вводить текст. Отсутствующие в OSM адреса могут не находиться.
- Разница времени вычисляется только по двум ответам маршрутизатора: A→магазин→B минус A→B. Это оценка без текущих пробок, парковки и времени покупки, не обещание времени прибытия. Отрицательная разница, возможная из-за эвристик маршрутизатора, отображается как 0.
- Для предварительного отбора используется геометрический коридор 5 км для автомобиля / 1.2 км пешком. Проверяются максимум 8 ближайших к линии пути магазинов; об ограничении и нерассчитанных заездах сообщается в интерфейсе. Это не исчерпывающая выдача всех возможных заездов. Фильтры 5/10/15 минут сравнивают реальные секунды, а не округлённые значения.
- Демо-сервисы работают без ключей, но без гарантий доступности. Внешняя сеть обязательна. Подсказки отложены на 800 мс, обращения ограничены примерно одним в секунду в локальном процессе. Для публичного запуска нужны собственные/договорные Photon и Valhalla, распределённый лимитер и подходящий поставщик тайлов. В Worker задайте переменные окружения отдельно; `.env.local` используется локально.
- При недоступности адресов, маршрута или геолокации есть сообщение и переход в обычный поиск; вымышленных цен, остатков и времени нет.

Документация: [Photon API](https://github.com/komoot/photon/blob/master/docs/api-v1.md), [Valhalla](https://valhalla.github.io/valhalla/api/route/api-reference/), [правила тайлов OSM](https://operations.osmfoundation.org/policies/tiles/).

## Проверки

`node scripts/test-journey.mjs` — допуск магазинов, закрытые/демо-данные, геометрический отбор, разница времени, маршрут через магазин и три товарных запроса. Изолированные фикстуры теста не записываются в каталог.

`node scripts/test-journey-live.mjs` — реальные адреса/маршруты Казани, автомобиль/пешком и три запроса через локальный API; требуется запущенное приложение и внешняя сеть. Положительный расчёт заезда проверяется на промежуточной точке, без публикации тестового магазина.

`node scripts/check-local-persistence.mjs` — сохранность пяти закрытых витрин и отсутствие их товаров в публичной выдаче.
