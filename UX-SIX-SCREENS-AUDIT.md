# Шесть экранов: аудит перед изменениями

Проверено по текущему `main` и локальной рабочей копии. Макеты задают расположение и стиль, а не достоверные товары, цены, отзывы или статистику.

| Экран | Уже работает | Требует доработки |
| --- | --- | --- |
| Главная | Поиск, диктовка, выбор города, геолокация, шесть категорий в модели, фото API | Компоновка по референсу, заметные категории, доступ к поиску по фото |
| Карта | Поисковая выдача, координаты только подтверждённых точек, маршруты, переключение списка/карты | Единый вид списка и карты, легенда происхождения, помощник без выдуманных предложений |
| Размещение | Существующий `/sell`, редактор товара, AI-черновик, фото | Пошаговая подача и проверка действий на мобильном |
| Профиль | Вход и кабинет продавца | Единый обзор объявлений без фиктивных метрик |
| Избранное | Сохранение личных данных в браузере | `#favorites` ошибочно открывает историю поиска; нужен собственный экран |
| Бизнес | `/connect`, `/business-demo`, `/onboarding`, импорт, кабинет | Единая визуальная подача и проверка полного пути публикации |

Ограничения данных: зелёный статус допустим только для опубликованного объявления продавца НайдиGo; найденный в интернете товар показывается отдельно без утверждения наличия. Адрес и точка на карте показываются только при подтверждённой привязке. Production и пользовательские данные на этом этапе не изменяются.

## Сделано в этой рабочей копии

- Главная: новый первый экран с полем поиска, голосом, поиском по фото и шестью категориями. Панорама Казани показывается только при выбранной Казани.
- Навигация: отдельные экраны избранного и профиля вместо повторного показа истории. Избранное читает существующие сохранения; фиктивных карточек и счётчиков нет.
- Карта результатов: единые точки и карточки, цвета меток по происхождению (продавец НайдиGo — зелёный, веб — синий, услуга — фиолетовый), помощник для уточнения запроса. Помощник запускает обычный поиск, не изображает самостоятельного агента для переписки.
- Для бизнеса: `/connect` показывает оффер, схему витрины, вход в существующее размещение, демо и форму заявки. Сам процесс `/sell` сохранён: место и продавец → товар и цена → проверка. На широком экране помощник расположен рядом с полями.
- Избранное: сердечко добавлено в карточки результатов. Отдельный экран показывает сохранённые товары, услуги и магазины, умеет искать, фильтровать и удалять. После входа данные объединяются с аккаунтом; последующие добавления и удаления записываются через существующую таблицу `buyer_personal` с контролем версии. При смене аккаунта сохранения разделяются.
- Профиль: показывает реальные объявления владельца из `/api/catalog`, фактическое число избранных и историю. Отсутствующие рейтинги, просмотры и сообщения в счётчики не превращаются.
- Поиск: страницы категорий с заголовками вроде «Купить по низким ценам» больше не выдаются за конкретный товар и не создают товарную метку на карте. Ссылка на подтверждённую страницу конкретного предложения видна прямо на карточке.

## Проверено

- `npm run typecheck`, `npm run lint`, `npm run build`, `npm run test:search`, `npm run test:seller`, `npm run test:ingestion`, `npm run test:buyer`, `npm run test:personal-api`, `npm run test:personal-sync` проходят. Lint: 0 ошибок, 71 предупреждение.
- В браузере: главная на desktop/mobile, переход по категории, пустые и заполненные состояния избранного/профиля, карта и помощник, бизнес страница и форма заявки (без реальной отправки), вход в локальный сценарий `/sell`, шаг товара и вызов помощника.
- Живой локальный поиск `велосипедный насос` в Казани: найдена карточка насоса HPS-295-3 на сайте продавца с фото, ценой 160 ₽, адресом, телефоном и ссылкой. Наличие корректно отмечено как требующее уточнения. Список и карта переключаются с сохранением результата.
- В браузере: сохранение реального результата в избранное, возврат после обновления страницы и удаление; профиль залогиненного локального тестового продавца с пустым состоянием объявлений без подмены данными макета.
- Повторная браузерная проверка: запрос «велосипедный насос» дал конкретный насос с ценой 160 ₽, фото, адресом, телефоном, прямой ссылкой и маршрутом. Страница категории Sportcity была обнаружена в товарной выдаче и исправлена. Путь `/connect` → кабинет магазина проверен; без магазина кабинет предлагает регистрацию.

## Осталось подтвердить до публикации

- Полный проход реальной публикации магазином с его учётной записью, фотографией и импортом CSV/XLSX в браузере. Автоматизированные тесты этих путей проходят, но браузерная приёмка с реальным магазином не выполнена.
- Полное пиксельное соответствие шести изображениям не достигнуто: макеты содержат выдуманные объявления, отзывы, рейтинг, счётчики сообщений и подтверждённое наличие. Экран размещения использует рабочие три шага действующего продукта вместо пяти нарисованных шагов.
- Качество внешнего поиска: тот же запрос добавил много магазинов «для уточнения». Дубль товарной страницы с тем же сайтом и адресом убран из списка и карты; остальные организации не выдаются за подтверждённый товар. Нужна дополнительная оценка релевантности сторонних организаций.
- Карта без запроса не показывает точки до получения конкретной выдачи; референс изображает наполненную карту, которую нельзя подменять вымышленными предложениями.
- CLI browser tests в этой среде не могут открыть localhost из-за `ERR_NETWORK_ACCESS_DENIED`; локальная браузерная проверка проведена через CUA.
- `test:onboarding` и `test:local-discovery` также не смогли подключиться к localhost из командного процесса (`EACCES`), поэтому их нельзя записать в пройденные. Серверные тесты продавца и импорта проходят, но полноценное создание магазина через браузер ещё требуется проверить в доступной среде.
- Production deploy не выполнялся по прямому ограничению задачи.
