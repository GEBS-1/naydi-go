# НайдиGo — локальная реализация поиска, 25 сентября 2026

## Статус

Изменён существующий проект, не создан новый сайт. В production ничего не опубликовано. Полный MVP 1.0 пока НЕ готов: реальные организации, карта и маршруты работают; сквозной поиск конкретных внешних товаров с ценами, универсальный ИИ-диалог и успешное распознавание фото ещё не подтверждены.

## Что реализовано

- Общий `/api/search`: публичный каталог + индекс D1 + Overpass + заменяемый WebSearchProvider. NDJSON сначала отдаёт индекс, затем внешние результаты. Не требуется регистрация покупателя.
- Реальные записи OpenStreetMap, URL первоисточника, время получения, доступные контакты/адреса/часы. Организация не выдаётся за подтверждённый товар. Без адреса нет точного маркера.
- Дедупликация, кеш геокодирования 7 дней, кеш Overpass 24 часа, индекс организаций 7 дней. Один запрос к публичному Overpass одновременно, 30 внешних запросов в час, тайм-ауты и пауза после ошибок.
- Режим маршрута использует тот же поиск: коридор вокруг геометрии Valhalla, максимум четыре кандидата, дополнительное время рассчитывается реальным маршрутом через точку. Ссылка Яндекс Карт сохраняет пункт назначения и промежуточный магазин. Ограничение: до 250 км по прямой; не полноценная навигация.
- Правила бюджета «до N», «не дороже N», уточнения «покажи дешевле», «не дальше N км», «лучше по дороге». Контекст в sessionStorage на 30 минут, без координат и фото. Новый самостоятельный запрос сбрасывает условия. Неизвестная цена показана отдельной группой, не как соответствующая бюджету.
- Строгий SearchResult в `lib/search-result.ts`. Обычная веб-страница остаётся источником, а не вымышленным product_offer. `matchType=similar` не заявляет доказанное точное совпадение.
- Голосовой ввод использует браузерный SpeechRecognition с текстовым fallback. Геолокация только после действия и объяснения, ручной адрес через Photon. Точные координаты остаются в памяти сценария; поисковая аналитика их не сохраняет.
- Фото: выбор JPG/PNG/WebP, уменьшение до 1024 px, удаление исходных метаданных при перерисовке, отдельное подтверждение передачи RouterAI, серверная валидация размера/ответа. D1/R2 не хранят фото пользователя. Успешное распознавание моделью пока НЕ проверено.
- Существующий планировщик закупок ищет первые шесть включённых позиций тем же движком. Генерация плана зависит от доступа к модели. Нет расчёта инженерных количеств.
- Централизованные будущие Free/Plus/Pro в `lib/plans.ts`, без оплаты и без ограничения базового поиска подпиской. Нет рекламного партнёра — нет фиктивной рекламы и искусственной задержки.
- Старый `/api/discovery` больше не обходит общий бюджет через Brave. Brave не нужен для поиска организаций.

## RouterAI — фактический результат

Проверены серверная переменная, Bearer-авторизация и `https://routerai.ru/api/v1`. Реальный прямой вызов ранее вернул HTTP 401. Это отказ авторизации сервиса, а не доказательство недоступности конкретной модели. Нельзя выбрать победителя Sonar/плагин по качеству без успешных вызовов.

Подготовленные точные ID:

| Назначение | ID | Статус |
|---|---|---|
| Генерация/план | `qwen/qwen3-30b-a3b-instruct-2507` | ID в официальном каталоге; успешный вызов не подтверждён |
| Веб-поиск | `perplexity/sonar` | Адаптер источников; успешный вызов не подтверждён |
| Узкие решения | `typesafe/jev-1.13` | Административный тест `/decisions`; не включён в обычный поиск |
| Фото | `qwen/qwen3-vl-8b-instruct` | Каталог подтверждает vision; фактическое распознавание не проверено |

`ROUTERAI_WEB_MODE=sonar` — кандидат по умолчанию; `plugin` — Exa; `plugin-native` — native; `off` — отключено. Одновременных вызовов Sonar и плагина для одного поиска нет. Свежего собственного товарного предложения достаточно, чтобы пропустить платный поиск. Native, Exa и Jev требуют проверки на доступном аккаунте; поддержки конкретной комбинации модель/плагин отчёт не утверждает.

Официальные форматы: [изображения](https://routerai.ru/docs/guides/overview/multimodal/images), [Jev](https://routerai.ru/docs/guides/overview/decisions/overview), [веб-плагин](https://routerai.ru/docs/guides/overview/plugins/web-search).

## Расходы и ограничения защиты

В D1 ведётся журнал вызовов, модели, токенов при наличии, времени, статуса, фактической стоимости в копейках. RouterAI `generation.total_cost` трактуется как RUB. Неизвестная стоимость никогда не записывается как ноль.

Месячный потолок приложения — 3 000 ₽, переменная может только уменьшить его. Перед вызовом резервируется 20 ₽; транзакционная проверка не допускает резерв выше остатка, одновременно выполняется один платный вызов. Предупреждения 50/80/100%. При неизвестном счёте последующие платные вызовы блокируются до сверки. Кеш и бесплатные источники продолжают работать. Есть лимиты гостя и глобальные лимиты; полноценный антибот/WAF не подключён.

Фактический журнал на момент проверки: два отказа RouterAI с нулевой учтённой стоимостью; один сетевой сбой с **неизвестной стоимостью**, под него сохранён резерв **20 ₽**. Это НЕ утверждение, что 20 ₽ списаны. Успешных платных генераций нет, сравнительная себестоимость моделей не измерена. Пять вызовов Valhalla в повторном тесте — успешны, стоимость публичного API 0 ₽.

ВАЖНО: резерв 20 ₽ не является доказанным верхним тарифным пределом провайдера. Поэтому абсолютный внешний финансовый потолок нельзя считать принятой функцией до настройки лимита в аккаунте RouterAI и проверки тарифов/счёта. Лимит у провайдера не настроен, автоматических пополнений нет. Не включать платный публичный трафик до этого.

## Запуск и конфигурация

```powershell
node scripts/run-framework.mjs dev --port 3000
node node_modules/typescript/bin/tsc --noEmit
node scripts/run-framework.mjs build
node scripts/check-local-persistence.mjs
node scripts/test-search-live.mjs
```

До миграций: `node scripts/backup-local.mjs`; при ошибке копирования R2 не считать полный backup готовым. Миграции: `node scripts/setup-local.mjs`. Не удалять `.wrangler/state`, не запускать сброс демо для подготовки production.

Секреты только в `.env.local`/server secrets: `ROUTERAI_API_KEY`. Остальные настройки: `ROUTERAI_MODEL`, `ROUTERAI_WEB_MODE`, `ROUTERAI_WEB_MODEL`, `API_MONTHLY_LIMIT_RUB`, `API_MAX_CALL_RUB`, `OVERPASS_URL`, `PHOTON_URL`, `VALHALLA_URL`, прежний `ADMIN_EMAIL`. D1 и R2 bindings сохранены. `.env.example` содержит имена без секретов. Локальный mock-login нельзя выставлять в интернет.

4. Полноценный семантический диспетчер/диалог, характеристики, подтверждённое «только новые», произвольные многосоставные уточнения — ещё не завершены. Текущий fallback — правила и категории OSM; он не универсальный LLM-поиск.

6. Публичные Photon/Overpass/Valhalla не дают SLA. Для production нужны разрешённые устойчивые endpoints, нагрузочные ограничения и эксплуатационный мониторинг. Авито и другие закрытые площадки не подключены.
