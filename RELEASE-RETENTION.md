# Хранение одной рабочей версии

По указанию владельца от 03.11.2026 сохраняется только текущий рабочий релиз
НайдиGo. Старые версии для отката после успешной выкладки не хранятся.

`scripts/deploy-vps.py` сначала собирает новую версию, сохраняет данные и проверяет
запуск и HTTPS. Затем устанавливает `/var/www/naydi-app/maintenance/prune-releases.py`
и запускает очистку с ожидаемым идентификатором текущего релиза. До успешных
проверок прежняя рабочая версия остаётся доступной для восстановления при сбое.
Правило записано также в серверном maintenance/retention.json и AGENTS.md.

Очистка проверяет current, start.sh, фактический каталог работающего процесса
PM2, состояние приложения и принадлежность всех удаляемых путей НайдиGo. Пути,
используемые процессами, статической раздачей, общими symlink или cron, защищены.
При смене релиза или появлении неподтверждённого нового развёртывания очистка
останавливается. Другие приложения, PostgreSQL, данные, фото, env и резервные
копии данных не удаляются.

Для обслуживания отдельно: `python scripts/prune-vps-releases.py` показывает план;
`python scripts/prune-vps-releases.py --apply` выполняет его. Результат сохраняется
локально в artifacts/storage. Рутинный успешный деплой выполняет очистку сам.

Выполненная очистка 03.11.2026: удалены девять прежних релизов и неиспользуемый
старый каталог кода/зависимостей. Освобождено 6 294 679 552 байта, свободно стало
11 373 256 704 байта. Остался релиз 20261103T100012Z. Проверка текущего процесса
и API после удаления прошла. База, фотографии и копии данных сохранены.
